# ES6 Classes

## Description
This project introduces ES6 classes: how to define them, add instance
and static methods, extend a class from another, and use basic
metaprogramming with symbols. It's part of the Holberton School
`holbertonschool-web_back_end` curriculum, under the `ES6_classes`
directory.

## Learning Objectives
By the end of this project, you should be able to explain, without the
help of Google:

- How to define a Class
- How to add methods to a class
- Why and how to add a static method to a class
- How to extend a class from another
- Metaprogramming and symbols

## Requirements
- All files interpreted/compiled on Ubuntu 20.04 LTS using `node 20.x.x`
  and `npm 9.x.x`
- Allowed editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
- All files should end with a new line
- Code uses the `.js` extension
- Code is tested using Jest (`npm run test`)
- Code is verified against lint using ESLint
- Full check: `npm run full-test`
