# ES6 Basics

## Description
This project covers the fundamentals of ECMAScript 6 (ES6), the 2015
update to JavaScript that introduced a large set of new language
features. It's part of the Holberton School `holbertonschool-web_back_end`
curriculum, under the `ES6_basic` directory.

## Learning Objectives
By the end of this project, you should be able to explain, without the
help of Google:

- What ES6 is
- New features introduced in ES6
- The difference between a constant and a variable
- Block-scoped variables
- Arrow functions and function parameters default to them
- Rest and spread function parameters
- String templating in ES6
- Object creation and their properties in ES6
- Iterators and for-of loops

## Requirements
- All files interpreted/compiled on Ubuntu 20.04 LTS using `node 20.x.x`
  and `npm 9.x.x`
- Allowed editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
- All files should end with a new line
- Code uses the `.js` extension
- Code is tested using the Jest Testing Framework
- Code is analyzed using ESLint with the project's specific rules
- All functions must be exported

## Setup

### Install NodeJS 20.x.x
\`\`\`
curl -sL https://deb.nodesource.com/setup_20.x -o nodesource_setup.sh
sudo bash nodesource_setup.sh
sudo apt install nodejs -y
\`\`\`

### Install dependencies
\`\`\`
npm install
\`\`\`

This installs Jest, Babel, and ESLint as specified in `package.json`.
